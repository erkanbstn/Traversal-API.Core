# Traversal API

Traversal seyahat sitesinin ziyaretçi verisini sunan API.

## Ne var

Uçlar `VisitorController` içindedir.

## Çalıştırma

Çözümdeki web veya API projesinde şu komutu çalıştırın:

```powershell
dotnet run
```

Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET 5, Entity Framework Core ve katmanlı yapı.
